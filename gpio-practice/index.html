GPIOA · GPIOB · GPIOC
16 pins per port

Find the bits for a pin. Each GPIO port has pins 0–15. MODER and PUPDR use two bits per pin: the lower bit is at position 2 × pin, and the upper bit is at 2 × pin + 1. For pin 5, those are bits 10 and 11. IDR and ODR use one bit per pin, so pin 5 uses bit 5 there.

Why AND clears a bit

AND produces 0 wherever the mask has 0, regardless of the old bit: 0 & 0 = 0 and 1 & 0 = 0. Where the mask has 1, AND keeps the old bit: 0 & 1 = 0 and 1 & 1 = 1. The ~ operator flips a mask, putting zeros at the bits you want to clear and ones everywhere else. Thus GPIOA->MODER &= ~BITPAIR(5); clears only pin 5's two MODER bits. The &= operator stores the AND result back in the register.

Why ORR sets a bit

ORR produces 1 wherever the mask has 1, regardless of the old bit: 0 | 1 = 1 and 1 | 1 = 1. Where the mask has 0, ORR keeps the old bit: 0 | 0 = 0 and 1 | 0 = 1. In C, this operation uses |. Thus GPIOA->MODER |= LBIT(5); sets only the lower MODER bit for pin 5. The |= operator stores the ORR result back in the register.

Configure MODER. Input mode is 00: clear both bits with GPIOA->MODER &= ~BITPAIR(5);. Output mode is 01: reset the upper bit with GPIOA->MODER &= ~UBIT(5);, then set the lower bit with GPIOA->MODER |= LBIT(5);. These masks leave the other pins unchanged.

Configure PUPDR for a button. An active-high switch connects the pin to high voltage when pressed. It needs a pull-down when released, so make its PUPDR pair 10: clear the lower bit with GPIOA->PUPDR &= ~LBIT(5);, then set the upper bit with GPIOA->PUPDR |= UBIT(5);. An active-low switch needs a pull-up, or 01: clear the upper bit with GPIOA->PUPDR &= ~UBIT(5);, then set the lower bit with GPIOA->PUPDR |= LBIT(5);.

Read IDR in the supplied if statement. GPIOA->IDR & BIT(5) keeps only pin 5's input bit. For an active-high button, (GPIOA->IDR & BIT(5)) != 0 is true when pressed. For an active-low button, use (GPIOA->IDR & BIT(5)) == 0. IDR is read-only; an assignment to it cannot change the button voltage.

Write ODR for an LED. With MODER set to output 01, use GPIOA->ODR |= BIT(5); to make pin 5 high and light the LED. Use GPIOA->ODR &= ~BIT(5); to make it low and turn the LED off.

These definitions from drivers.h are available in the practice code area. You do not need to type them.

#define BIT(x)     (1 << x)
#define BITPAIR(x) (0b11 << (x*2))
#define UBIT(x)    (0b10 << (x*2))
#define LBIT(x)    (0b01 << (x*2))

// Port struct
typedef struct{
    uint32_t MODER;   // offset: 0x00
    uint32_t OTYPER;  // offset: 0x04
    uint32_t OSPEEDR; // offset: 0x08
    uint32_t PUPDR;   // offset: 0x0C
    uint32_t IDR;     // offset: 0x10
    uint32_t ODR;     // offset: 0x14
} Port;

// Port addresses
#define GPIOA ((Port*) 0x48000000) // base address of GPIO Port A
#define GPIOB ((Port*) 0x48000400) // base address of GPIO Port B
#define GPIOC ((Port*) 0x48000800) // base address of GPIO Port C
